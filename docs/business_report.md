## 1. Цель работы

Реализовать главную бизнес-операцию системы онлайн-записи — создание и управление записями клиентов на тренировки. В отличие от справочников, бизнес-операции работают с транзакционными данными и требуют сложной логики: проверка доступности временных слотов, предотвращение двойных бронирований, управление статусами записи, перенос записи и формирование отчётов.

## 2. Реализованные страницы

В ходе работы были разработаны следующие страницы и скрипты.

**booking.php** — главная страница создания записи. Реализована пошаговая форма с динамической загрузкой данных. Пользователь выбирает услугу (группу), после чего через AJAX подгружается список тренеров, которые ведут эту услугу. Затем выбирается дата и автоматически загружаются свободные временные слоты. После выбора слота открывается форма для ввода данных клиента: фамилия, имя, дата рождения спортсмена, телефон и email родителя. Перед сохранением на сервере выполняется повторная проверка, что выбранный слот всё ещё свободен (защита от конкурентных бронирований). При успешном создании записи пользователь видит сообщение с номером записи и перенаправляется на страницу списка.

**appointments_list.php** — страница управления записями. Отображает таблицу со всеми записями, содержащую дату и время, спортсмена, услугу, тренера и статус. Реализованы фильтры по статусу (новая, подтверждена, отменена, завершена), по тренеру и по диапазону дат. Настроена пагинация (20 записей на страницу). Статусы выделены цветными индикаторами для наглядности. Каждая запись имеет кнопку «Просмотр» для перехода к деталям.

**appointment_view.php** — страница детального просмотра записи. Показывает всю информацию о записи: дата и время, данные спортсмена (фамилия, имя, дата рождения, телефон родителя, email), услуга, тренер, статус. На странице доступны кнопки «Назад» (возврат к списку), «Перенести» (переход к форме переноса записи) и «Отменить» (с подтверждением). При отмене записи статус меняется на «отменена», а временной слот освобождается.

**reschedule.php** — страница переноса записи. Пользователь выбирает новую дату, после чего через AJAX загружаются свободные слоты. При выборе нового времени выполняется проверка, что слот не занят, затем обновляется дата и время записи. После успешного переноса пользователь возвращается на страницу деталей записи с обновлёнными данными.

**reports.php** — страница отчётов. Содержит три отчёта. Первый отчёт — количество записей по дням за выбранный месяц. Второй отчёт — рейтинг тренеров по количеству проведённых тренировок. Третий отчёт — количество отменённых записей за выбранный период. Каждый отчёт представлен в виде HTML-таблицы и имеет кнопку «CSV» для экспорта данных в файл. Экспорт реализован через скрипт export_csv.php, который генерирует файл на лету с правильной кодировкой UTF-8.

**get_available_slots.php** — вспомогательный AJAX-скрипт. Принимает параметры service_id, coach_id и date. Возвращает JSON-массив свободных временных слотов на выбранную дату для указанного тренера. Учитываются уже существующие записи, рабочие часы (с 9:00 до 18:00) и обеденный перерыв (13:00-14:00).

**get_coaches_by_service.php** — вспомогательный AJAX-скрипт. Принимает service_id и возвращает JSON-массив тренеров, которые ведут выбранную услугу.

## 4. Защита от конкурентных бронирований

При создании записи реализована двухуровневая проверка. На клиентской стороне пользователь видит только свободные слоты, но этого недостаточно. На сервере перед вставкой записи выполняется повторный запрос: SELECT COUNT(*) FROM enrollments WHERE coach_id = ? AND enrollment_date = ?. Если за время, пока пользователь заполнял форму, другой клиент успел записаться на тот же слот, операция отклоняется с сообщением: «Это время только что заняли. Выберите другое». Вся операция (проверка и вставка) обёрнута в транзакцию для атомарности.

---

## 5. Динамическая загрузка через AJAX

Для удобства пользователя все зависимые списки загружаются без перезагрузки страницы. При выборе услуги отправляется fetch-запрос к get_coaches_by_service.php, который возвращает JSON с тренерами. При выборе тренера и даты отправляется запрос к get_available_slots.php, который возвращает свободные слоты. Слоты отображаются в виде кнопок, при нажатии на которые форма отправляется с выбранным временем.
